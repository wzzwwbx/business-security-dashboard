events ──→ triggers ──→ functions ──→ items ──→ hosts ──→ interface
(事件)     (触发器)     (函数)        (监控项)   (主机)     (接口/IP)

| 步骤 | 表                       | 关联字段                                     | 说明                                              |
| ---- | ------------------------ | -------------------------------------------- | ------------------------------------------------- |
| 1    | `events` → `triggers`    | `events.objectid` = `triggers.triggerid`     | 事件定位到触发它的触发器（source=0, object=0 时） |
| 2    | `triggers` → `functions` | `triggers.triggerid` = `functions.triggerid` | 触发器关联的函数                                  |
| 3    | `functions` → `items`    | `functions.itemid` = `items.itemid`          | 函数关联的监控项                                  |
| 4    | `items` → `hosts`        | `items.hostid` = `hosts.hostid`              | 监控项所属主机                                    |
| 5    | `hosts` → `interface`    | `hosts.hostid` = `interface.hostid`          | 主机的网络接口（取主接口）                        |
