# Overview 页面现场展示解说词

## 一、建议现场解说词

各位领导，下面展示的是业务安全态势系统的综合态势首页，也就是 Overview 页面。

这个页面的定位不是替代密信、签阅、零信任或运维系统，而是把多个业务和安全来源的数据汇聚到一起，按照统一的人员、终端、区域、业务和安全事件关系进行分析呈现，帮助值班人员快速回答三个问题：当前整体运行情况怎么样、风险发生在哪里、发现问题以后如何联动处置。

首先看页面上方的四项综合指标。第一项是在线用户与用户总数，用来观察当前纳管人员的在线情况；第二项是今日密信消息收发量，体现当前业务活动规模；第三项是待处置告警，汇总终端、安全设备和零信任等来源的风险线索；第四项是签阅收到和已处理数量，用于观察签阅业务的当前处理情况。这里的数量和状态是对来源数据的统计呈现，不代表态势系统替代业务系统对业务结果作出保证。

中间是区域和业务安全态势地图。地图展示已纳管区域、人员接入情况以及地面信道和卫星信道的连接关系。选择区域后，可以进一步查看对应人员、终端、业务活动和安全事件。对于跨区域链路，系统可以展示线路状态、链路流量和相关节点，便于从区域层面定位影响范围。

左侧是用户和部门收发排名。这里支持总量、发送和接收三个维度切换，用于观察业务活动分布。点击人员可以进入人员详情，查看所属单位、区域、终端地址、装备套件、安全事件和业务活动；点击部门可以查看部门整体的在线情况、业务量和关联安全事件。这个模块的重点是把业务数据和人员、部门关系关联起来，而不是只展示一个孤立的数量。

右侧上方是今日业务摘要，展示密信消息、文件和签阅的收发及处理数量，并滚动显示近期业务活动。右侧下方是区域运行状态，展示各区域在线情况、接入信道和当日流量，可以快速识别当前活跃区域以及需要关注的区域。

页面底部左侧是业务系统流量，展示密信、签阅和密盒等核心业务系统的吞吐趋势。这里反映的是来源系统上报或提供的流量数据，用于观察业务活动变化和链路压力；如果需要查看具体业务系统，可以点击进入业务态势专题页面。

底部中间是告警处置中心。系统把安全来源产生的告警集中展示，并区分高危待处置、人工通知和策略联动状态。点击一条告警，可以查看风险等级、关联人员、风险来源、智能研判依据和处置方式。对于支持自动联动的场景，系统可以生成最小影响范围的处置策略；对于需要人工确认的场景，则提示责任单位先进行核验。所有处置动作都应以实际执行结果和审计记录为准，不能只以告警消失作为处置完成。

底部右侧是签阅处置，展示签阅收到、已处理、待处理和异常退回数量，并计算当前处理进度。这个模块用于呈现签阅系统提供的业务状态，具体业务是否完成、是否成功，仍以签阅系统的权威结果为准。

整个 Overview 页面形成了从数据汇聚、态势分析到事件处置的闭环：上方看总体摘要，中间看区域和关联关系，两侧看人员、部门和业务状态，底部看流量、告警和签阅处置。对于发现的异常，系统支持从告警下钻到人员、终端、区域和处置策略，帮助值班人员缩短从发现问题到定位问题的时间。

以上是综合态势首页的主要能力。后续还可以根据密信、签阅和其他业务系统提供的真实字段，逐步增加数据分析类型和呈现维度，但所有正式指标都会以明确的数据来源、统计口径和可追溯明细为前提。

## 二、现场演示建议顺序

1. **先讲系统定位**：这是多源数据汇聚和分析呈现平台，不替代来源业务系统。
2. **讲顶部四项指标**：在线用户、密信收发、待处置告警、签阅处理。
3. **讲中心地图**：区域、人员、终端、地面/卫星信道和影响范围。
4. **点击一个区域或人员**：展示人员详情、装备状态和安全事件关联。
5. **切换用户/部门排名**：说明业务活动可以下钻到人员和组织。
6. **点击一条安全事件**：展示风险来源、智能分析和处置策略。
7. **展示底部三个模块**：业务流量、告警处置、签阅处理。
8. **最后强调边界**：态势系统负责汇聚、分析、呈现和联动留痕，业务成功结果以密信、签阅等来源系统为准。

## 三、现场操作提示

- 如需制造一条新的安全事件，可点击“告警处置中心”标题右侧的刷新按钮；
- 点击告警列表中的事件，可打开处置策略详情；
- 高危事件可演示“电话通知”和“下发处置策略”；
- 点击“今日业务摘要”可进入业务态势的密信专题；
- 点击“业务系统流量”可进入系统流量专题；
- 点击“签阅处置”可进入签阅专题；
- 安全事件列表支持在面板内纵向滚动，查看完整事件列表；
- 现场应将页面中的实时数据称为“演示数据”或“来源数据统计”，不要表述为真实生产业务成功率或安全保障承诺。

## 四、建议现场收尾语

综合态势首页的核心价值，是把分散在不同业务和安全系统中的数据统一汇聚，通过人员、终端、区域、业务和事件之间的关联分析，形成可观察、可定位、可下钻、可留痕的安全业务态势。后续接入真实系统后，可以在保持现有展示框架的基础上，继续扩展分析类型、数据量统计和安全保密分析维度。
