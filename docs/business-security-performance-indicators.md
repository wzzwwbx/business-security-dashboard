# 业务态势系统安全保密数据分析指标

## 指标定位

业务态势系统的数据来源为密信、签阅、数字信封等业务系统，本系统只负责数据接入、分类统计、分析结果生成和态势呈现，不对密信发送成功率、签阅完成率、加解密成功率等业务系统自身结果负责。

## 建议考核指标

1. **保密数据接入与分析量**：在双方确认纳入本期建设的业务系统范围内，态势系统每月完成接入、去重和分类统计的保密业务数据记录不少于 **1000 条**，并能够按来源系统、行为类型和统计时间查询。

2. **保密数据分析类型**：态势系统至少支持登录、文件收发、文件下载、文件加解密、签阅等已确认行为中的 **3 类**数据分析，并形成对应的数量统计或趋势结果。

3. **安全保密态势呈现维度**：业务态势页面至少呈现来源系统、行为类型、时间趋势、数据数量和异常记录等 **5 个分析维度**，且各维度能够关联到统计周期和数据来源。

## 统一说明

- 以上指标考核的是态势系统的数据接入、分析和呈现能力，不考核密信、签阅等业务系统自身的业务成功率。
- “不少于 1000 条”仅适用于本期已确认纳入范围且实际产生业务数据的月份；若实际业务量不足 1000 条，以实际产生量为准核验，不能通过虚构数据补足，也不因业务量不足判定态势系统分析能力不达标。
- 未纳入本期建设范围的业务系统和行为类型不计入考核范围，范围调整应形成书面确认记录。
- 数据记录数量应能够从接入批次、原始记录和分析结果中核对；重复数据、测试数据、Mock 数据和演示数据不计入有效分析数量。
- 指标按月核验，核验材料至少包括数据来源、统计周期、记录数量、分析类型、呈现截图或查询结果。
- “分析维度”是指能够独立筛选、统计或展示的维度，不要求每个维度都具备业务系统成功率字段。
- 业务系统负责提供真实业务日志和业务结果，态势系统负责接收、归一、统计、分析和呈现；业务系统结果由业务系统自身负责。

## 验收依据

每项指标均应能够通过态势系统的接入记录、分析结果和查询页面进行现场核验；数量以系统明细为准，维度以已配置并可查询的分析项为准，避免只依据页面静态文字或人工填报结果判断。
